# Кафе: отдельный зонт, 96 px/м

По новому решению владельца зонт стоит рядом со столом на собственной тяжёлой латунной подставке. Вид сверху спереди около 35°, купол с чистыми винными/светлыми полосами. Стол и два кованых стула — независимые предметы. Стол скопирован без изменения прежнего standalone-рисунка; бутылка в центре допустима, стойки в нём нет.

Новая композиция заменяет прежнюю сборку из street96 с шестом через стол. Не использовать старые bank_umbrella_pole_front/bank_bistro_table_parasol в новой сборке. Позиции в manifest — пример QA, не обязательная расстановка. Стол/стулья и палитра сохранены побайтно. Зонт — новая концептная основа с очисткой на целевой сетке; не нативный 3D-рендер.

У каждого предмета собственная опора и радиус столкновения. Альфа жёсткая, сетка 96 px/м; падающие тени и свет даёт движок. Никаких новых настроек света или игровых изменений в source/. Художественное принятие нового зонта не заявлено.
