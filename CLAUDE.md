# TrashSquad — правила работы (Beer Party Studio)

- Приоритет — оптимизация (FPS, нагрев, вылеты на слабых телефонах; в первую очередь режим «Выживание»).
- Разрешены улучшения графики, анимаций, интерфейса, сюжета и механик. Сохранять читаемость боя и производительность на Galaxy A13.
- Рабочая ветка — big-build. Публикация в main только по команде «выпускай».
- APK всегда называется TrashSquad; в сборках/описаниях упоминать Beer Party Studio.
- Коммиты, PR и релизы: короткий заголовок и 1–2 предложения о результате. Проверка — одной строкой. Без служебных подписей, пересказа переписки и упоминаний помощников. Подпись Beer Party Studio обязательна.
- Историю Git переписывать только после отдельного подтверждения.
- Присланные скриншоты и видео — конфиденциальны: никуда не сохранять (ни в репозиторий, ни в файлы), после разбора удалять копии.
