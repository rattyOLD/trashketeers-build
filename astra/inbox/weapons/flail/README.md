# «Цепной пёс» — арт по брифу v30

Шесть PNG RGBA с прозрачным фоном. Исходники сохранены в большом разрешении.
Стиль: графитовая сталь, ржавые болты, чёрная изолента, приглушённая олива,
оранжевые искры. Рукоять направлена вправо: хват слева, крепление цепи справа.

## Подготовка игровых размеров

Нужен Python 3 и Pillow. Из этой папки:

```sh
python3 prepare_assets.py --output ready
```

Скрипт сохраняет исходники, приводит статичные спрайты к размерам брифа,
отдельно собирает четырёхкадровые листы с одинаковым масштабом и общим центром.
Координаты исходных кадров указаны в `manifest.json`; у вспышки граница
первого кадра сдвинута, чтобы не обрезать искры второго кадра.

| Файл | Размер после подготовки | Кадры |
| --- | --- | --- |
| flail_handle.png | 150×60 | 1 |
| flail_ball.png | 64×64 | 1 |
| flail_ball_fast.png | 384×64 | 4, ячейка 96×64 |
| flail_link.png | 16×16 | 1 |
| flail_icon.png | 256×128 | 1 |
| flail_hit.png | 512×128 | 4, ячейка 128×128 |

## Передача в игру

Подготовленные PNG предназначены для `source/assets/weapons/`.
Листы читаются слева направо. Начальный ориентир воспроизведения:
вращение — циклом 12–16 FPS, удар — однократно 16 FPS.
`flail_ball_fast.png` заменяет обычный шар при высокой скорости;
цепь выкладывается из `flail_link.png`, эффект удара — на `ball_hit`.
Точки хвата и крепления рукояти уточнить при подключении к слою руки героя.

Проверены формат RGBA, наличие альфы, прозрачные края и четыре визуально
раздельных кадра на обоих листах. Это исходники арта: нормализация скриптом
и проверка в Godot в этой задаче не выполнялись. Физика и код игры не менялись.
