# Рико — контрольный idle, 96 px/м

Один кадр в ячейке **256×256**, основной рисунок168px/1,75м, полный видимый силуэт с обводкой170px. Опора **[128,224]**; для Sprite3D pixel_size=1/96 и offset=Vector2(0,96).

Новая попытка сохраняет исходного рыжего Рико: морду/очки, шарф, меховой воротник, куртку, cargo-брюки, сапоги и хвост. Куртка отделена от меха более тёмными оттенками, у кожи читаются складки и швы, у морды — нос и улыбка. Idle принят владельцем как эталон в обновлении брифа e099467. Это один контрольный кадр, не готовая анимация и не сдача всей партии.

## Файлы

- raccoon_idle.png: одна ячейка256×256,127 видимых цветов, прозрачность0/255, непрерывный тёмный контур1px.
- raccoon_idle_n.png: карта нормалей256×256RGB, OpenGL+Y, нормализованные векторы. Получена из вручную заданных форм и профилей складок, не из яркости albedo. Начальная сила **0.25**: рельеф не должен мешать читаемости лица.
- ../palettes/chars.png:128цветов. Это палитра контрольного персонажа; общая палитра новой главы будет сведена с материалами после оценки.
- manifest.json: размеры, SHA256, опора, нормаль, состояние сдачи; VALIDATION.json — проверки.

## Подготовка

По новому разрешению владельца можно строить от концепта. Источник rico96_source.png в previews — крупный рисунок по исходному листу героя. Для игрового файла он обработан на целевой сетке: медианные пробы цвета внутри пикселя, ограничение палитры, удаление одиночных близких оттенков, жёсткий силуэт и полный тёмный контур. Это **концептная основа с пиксельной очисткой**, а не утверждение, что исходник был нарисован сразу в256×256. Падающей тени и цветного света в albedo нет.

Воспроизведение (Node18+, к игре не относится):

```bash
node tools/art_v36/prepare_rico96.mjs astra/previews/v36/rico96_source.png /tmp/rico96
```

Повторный расчёт в доступном JavaScript-исполнителе побайтно воспроизвёл оба PNG. Проверены PNG CRC/zlib Adler, SHA256,128уникальных цветов палитры/127в рисунке, альфа0/255,170px силуэта, полный контур, единая связная фигура,6117векторов нормалей с ошибкой длины<0.006.

## Проверка в движке

Godot4.4.1 Compatibility отрендерил отдельную копию настоящего прототипа Банка: день/вечер, нормали вкл/выкл и тень вкл/выкл. NodeCLI побайтно воспроизвёл albedo и нормаль. Нормали меняют4180/3319px днём/вечером, максимум4/255 на канал: эффект мягкий, лицо остаётся читаемым. Отключение тени изменяет3919px с максимумом71/255: контактная тень создаётся движком. Ошибок сцены/скриптов нет; системное предупреждение V-Sync. Результаты — RENDER_VALIDATION.json; кадры previews/v36/rico96_plaza_day/evening.png.

Это статическая проверка одного кадра, не анимация и не бой. Свет/камера QA перечислены в tools/art_v36/qa_plaza.py; исходный source/ не изменялся. В сцене остаются старые48px/м материалы/предметы и временные фасады; мобы скрыты. Размытие/свечение Compatibility здесь реализованы экранным mip-проходом прототипа, не физической глубиной резкости камеры. Художественная оценка владельца остаётся открытой.

Прежние материалы и предметы48px/м — исторический тест. Комплект96 теперь содержит один кадр Рико и три предмета: фонарь, тумбу, кадку; см. ../props/README.md. Бег8кадров, материалы192×192 и мобы — после оценки владельца. Рабочий source/, main и живые Web/APK этим пакетом не меняются.
