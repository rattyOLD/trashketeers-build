# v36 — семь материалов 192×192, 96 px/м

Готовы к просмотру три варианта каждого: cobble_gold, cobble_worn, rose_path, marble, lawn, stone_wall, step_riser. **42 новых PNG:21 albedo+21 нормаль.** Каждая плитка покрывает прежние2×2м. Чистая непрозрачная поверхность без обводки и падающих теней.

Грубые прежние96×96 не увеличивались: новая концептная основа materials96_source.png обработана на сетке192 медианными пробами, спокойной палитрой и тороидальной очисткой границ. Розовый приглушён до камня; мрамор светлый с тонким золотом; газон живой зелёный. Три варианта меняют внутренние детали при одинаковом краевом окружении. У регулярной кладки/ступеней геометрия рядов сохраняется.

Нормали192×192RGB, OpenGL+Y, linear data, invert_y=false; начать с0.35. Это **приблизительный неглубокий рельеф швов по структуре текстуры**, не геометрический3D-бейк и не скан. Плоскости камня преимущественно плоские; не выдавать эту карту за скульпт. В прототипе сила общего материала пока задаётся его кодом.

Палитра семи материалов — palettes/materials96.png128. Принятые спрайты/их цвета сохранены; окончательное сведение авторских палитр до палитры главы ещё впереди. Импорт: repeat enabled, nearest with mipmaps, физический масштаб2м независимо от размераPNG.

**Честная частичная миграция:** garden_soil, plaster, roof_red — прежние96×96/48px/м (12PNG) с сохранёнными SHA. Они не входят в семь новых материалов и не объявляются192px. manifest помечает плотность каждого файла и uniform_density=false. Штукатурку/черепицу следует обновить вместе с фасадами; землю клумб — отдельным продолжением. Восьмая клетка большого исходного атласа — не сданная игровая текстура.

Проверка:54PNG включая12 прежних;42 новых файла побайтно воспроизведены. Для семи семейств проверены126 пар краёв albedo и126 пар нормалей в обоих направлениях, включая самоповтор и произвольных соседей. Контраст/luma и зелёный газон проверены отдельно. Заведомо повреждённый край с правильными SHA/размерами отклонён. Нет искусственной одноцветной рамки по периметру.

Godot4.4.1 Compatibility: отдельная копия настоящей площади, принятые Рико/фонарь/тумба/кадка, новые материалы, день/вечер. Ошибок сцены/скриптов нет; системный V-Sync warning. Кадры materials96_plaza_day/evening.png, повтор плиток materials96_repeat.png. Это статический контроль; временные фасады/прочий реквизит ещё старые, мобы скрыты. Эффекты Compatibility здесь экранные, не физическаяDOF. Художественная оценка новых материалов открыта.
