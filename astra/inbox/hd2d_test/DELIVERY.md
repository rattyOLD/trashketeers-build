# v38 — текущая сдача HD-2D

Сводный порядок — astra/from_claude/BRIEF_v38_bank_plan.md, архитектура — v37. Работа ограничена площадью Банка. Правила 96 px/м действуют.

**Первый этап v38: buildings/bank_hall.glb и внешние текстуры.** Банк в настоящем 3D: корпус 16×10,5×8 м, 5 993 треугольника, общий trim sheet 1024, стены/черепица 192, нормали, отдельные маски окон/фонарей. Размеры, опора, коллизия и материалы — в manifest. README объясняет подключение.

Модель проверена численно и загружена в Godot 4.4.1. Есть Blender-кадр с игровой камерой, день/вечер/поворот в Godot и контроль нормалей. Кадры astra/previews/v38/bank_*; облегчённые JPG и исходные PNG. Это отдельная проверка банка рядом с принятым Рико, не готовая площадь и не игровой тест. Художественное принятие 3D-банка пока не заявлено.

Прежние v36-пакеты Рико, фонаря/тумбы/кадки, материалов, балюстрады и независимого кафе остаются в своих папках. Часть старых файлов историческая: для текущего кафе использовать props/cafe96, без шеста через стол. Старые правила 32/48 px/м не относятся к новой сдаче.

Дальше по v38: один pig_guard idle для оценки, бег Рико, навесной декор, ground96, передний план/горизонт. Кафе и лавка в 3D из общего набора — после оценки банка; их ориентир 7,5 м. Прежние незавершённые заготовки не считаются готовой сдачей этих этапов.

Рабочий source/, main и живые Web/APK этой сдачей не изменялись. Установку в площадь, атмосферу и показ боя выполняет разработчик по v38.
