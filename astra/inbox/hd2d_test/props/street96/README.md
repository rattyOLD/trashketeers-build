# v36 — балюстрада и кафе, 96 px/м

Базовая балюстрада **принята владельцем**. Её albedo и normal сохранены побайтно. Варианты02/03 и исправленный комплект кафе — новые образцы для оценки.

## Состав

- bank_balustrade.png, bank_balustrade_02.png, bank_balustrade_03.png — секции192×128, опора96,126; видимый рост100px. У каждого своя _n.png.
- bank_umbrella.png —288×272, опора144,270, видимый рост250px. **Виден верх полосатого купола, ракурс сверху спереди~35°**, изнанка/спицы не раскрыты. Это исправление прежнего неверного вида снизу.
- bank_bistro_table_parasol.png —128×128, опора64,126. Отверстие в центре **[64,57]**, бутылка слева, чашки справа.
- bank_chair_left/right.png — два отдельных кованых стула128×128, опора64,126; по100px видимого роста, тёмное железо/латунь/винные сиденья.
- bank_umbrella_pole_front.png — только слой верхнего шеста до отверстия столика. Не отдельный предмет: без коллизии и собственной тени.
- bank_bistro_table.png — прежний отдельный столик с бутылкой в центре; **под зонт не использовать**.

## Стыки и варианты балюстрады

Повторять через **2м**, без промежутка между полными192px ячейками. У секции нет торцевых столбов. Кромки albedo с альфой и нормали совпадают у любых соседей; общие8px у торцов сохранены. На открытом горизонтальном стыке нет вертикальной чёрной линии: это соединение, а не внешний силуэт. Остальная граница — тёмная1px обводка.

У вариантов сохранены принятые силуэт/цвета/геометрия; изменены только внутренние участки со сколами и трещинами (287/286px). Повреждения взяты из отдельно нарисованных вариантов концепта, не случайным шумом. Нормали — исходные формы балясин/плоскостей плюс неглубокие канавки по маскам повреждений. OpenGL+Y, linear, invert_y=false; начать с0.35. Это приблизительный авторский рельеф, не скан.

## Сборка кафе

Все части стоят в общей наклонённой плоскости с общей опорой на земле. Положение каждого — в manifest/assembly:

1. Зонт:0,0,0.
2. Стулья:±65/96м поX, глубина0.005м.
3. Столик под зонт:0,0,0.025м.
4. Верхний шест:0,0,0.04м, без тени/коллизии.

Верхний шест заканчивается на высоте отверстия столика69/96м и перекрывает столешницу до его центра. Ниже скатерть скрывает шест. Это исключает появление шеста из задней кромки и конфликт с бутылкой. При физическом3D-шесте в движке этот вспомогательный слой не нужен. Коллизии сборки: столик и оба стула; дополнительную коллизию стойки зонта отключить.

## Пиксель и проверка

Общая **street96.png128** сохранена для всех этих предметов. Жёсткая альфа0/255, единая сетка, nearest/mipmaps, alpha scissor0.5, никакой падающей тени в albedo. Купол прошёл очистку цветовых кластеров внутри материалов и отдельные семитоновые рампы ткани: без мягкой альфы, фото-градиентов и шумного дизеринга. Большие cafe96_source.png и rail96_variants_source.png — концептные основы, **не игровые PNG**.

12PNG проверены по SHA/CRC, размеру/метрам/опорам, палитре/альфе/контуру/связности, любым стыкам трёх секций и нормалей, сохранности принятой основы, отверстию и совмещению слоя шеста. Повторный экспорт воспроизводит пакет. Godot4.4.1Compatibility: новая земля, смешанный ряд секций и полное кафе рядом с Рико; день/вечер без ошибок сцены/скриптов. Системный V-Sync warning. Превью cafe96_plaza_day/evening.png и cafe96_review.png (точное×2 без интерполяции).

Это статический контроль в копии настоящего прототипа: временные фасады/прочие старые предметы остаются, мобов нет. Рабочий source/, main/Web/APK не меняются. Новые варианты/кафе ещё не одобрены художественно.
