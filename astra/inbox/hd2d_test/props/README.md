## Подключение — старые опоры больше не подходят

Плотность всех новых материалов и предметов **48 px/м**. `pixel_size = 1.0/48.0`. В `manifest.json` — размеры в метрах, опоры и радиусы столкновений. Опоры — координаты границ пикселей от верхнего левого угла. Для Sprite3D с `centered=true`:

```gdscript
sprite.offset = Vector2(width * 0.5 - anchor_x, anchor_y - height * 0.5)
```

Тумба в обзорном холсте стоит в `[0,77]`, фонарь — `[20,0]`, общая опора `[52,164]`. Сокет фонаря на тумбе `[52,14]`; смещение опоры фонаря **73/48 м** вверх в общей плоскости спрайтов. При наклоне повернуть и это смещение. Добавить `0.005 м` по нормали к камере против z-fighting. Столкновение в сборке только у тумбы; радиус 0.76 м.

Albedo — sRGB, бинарная альфа, nearest с mipmaps. Карты данных — линейные, без художественной цветокоррекции. Для нормали OpenGL `normal_map_invert_y=false`, начальная сила 0.45. Нормаль получена отдельным геометрическим проходом, не из яркости рисунка.

## Стекло

**EMISSION_OP_MULTIPLY**, не ADD. Маска содержит три намеренных уровня: чёрный 0 у железа, переплётов, крыши и блика; 48 у стекла; 255 у нити. Это интенсивность свечения, не прозрачность: альфа albedo остаётся 0/255. Не бинаризовать маску при импорте — иначе стекло снова станет сплошным ярким прямоугольником.

Днём энергия 0; вечером начальное значение 0.45–0.55, цвет `#ffc574`; OmniLight начать с 0.4, дальность 5 м. Два внутренних железных переплёта остаются чёрными в маске по всей проверяемой высоте.
