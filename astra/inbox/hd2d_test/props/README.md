# v36 — модульный образец, 48 px/м

Три новых спрайта и две карты данных для просмотра в площади Банка. **Это кандидат для художественной оценки одного комплекта, не завершённый набор v36.** Остальные пропсы, фасады и новые персонажи ещё не сданы.

| Файл | Размер | Назначение |
|---|---:|---|
| `bank_lantern.png` | 72×104 | Железо, латунь, янтарное стекло с нитью, завитки |
| `bank_pedestal.png` | 96×72 | Каменные блоки, сколы, резная панель, карниз, мох и плющ |
| `bank_flower_planter.png` | 96×100 | Рифлёная терракота, пышная листва, плети, цветы разных размеров |
| `bank_lantern_glow.png` | 72×104 | Белая маска стекла на чёрном, без ореола |
| `bank_pedestal_n.png` | 96×72 | Нормаль камня OpenGL +Y, из геометрии резьбы |

Спрайты созданы из объёмных форм сразу в конечном разрешении. Затем закодированы ступенями материалов общей палитры, добавлена однопиксельная цветная обводка. Большая принятая иллюстрация не уменьшалась. Есть мягкое верхнее освещение формы и затенение углублений; падающей тени на землю и цветного света нет. Это способ подготовки новых спрайтов, а не замена плоскими вырезками старого рисунка.

## Сборка

`manifest.json` содержит точные размеры в метрах, опоры и радиусы столкновений. Плотность **48 px/м**, `Sprite3D.pixel_size = 1.0 / 48.0`. Не применять эту плотность к текущему Рико или прежним материалам 64×64/2 м.

Опоры заданы непрерывными координатами границ пикселей от верхнего левого угла. Для `centered=true`:

```gdscript
sprite.offset = Vector2(width * 0.5 - anchor_x, anchor_y - height * 0.5)
```

Фонарь с тумбой занимает холст 96×165 px. Видимый силуэт — 163 px, то есть **3.396 м**; с прозрачными полями холст — 3.4375 м. В обзорном холсте тумба стоит в `[0,93]`, фонарь — `[12,0]`, общая опора `[48,164]`.

В 3D тумба стоит опорой на земле, опора фонаря смещена на `61/48` м вверх в **той же плоскости спрайта**. Если спрайты наклонены, повернуть вместе с этой плоскостью и вектор смещения. Для фонаря добавить `0.005` м к нормали плоскости в сторону камеры: это предотвращает борьбу глубины у перекрывающихся плоскостей. У собранного объекта включено столкновение только тумбы. Для отдельной установки фонаря использовать его собственный радиус.

## Стекло и нормаль

- Albedo — sRGB; альфа только 0/255; nearest с mipmaps по настройке сцены.
- Маски/нормали — данные, без палитризации и цветокоррекции при импорте.
- Стекло: **умножение** цвета эмиссии на маску, `EMISSION_OP_MULTIPLY`. При сложении весь корпус начинает светиться. Днём энергия 0; для начала вечером цвет `#ffc574`, энергия 0.55. Отдельный настоящий свет: начальная энергия 0.4, дальность 5 м. Это стартовые значения из QA, не обязательный баланс всей площади.
- Камень: normal map OpenGL **+Y**, `normal_map_invert_y=false`, начальная сила 0.45. Карта получена отдельным проходом нормалей тех же объёмных форм и на той же сетке; яркость albedo для рельефа не использовалась.

## Проверка и ограничения

`python tools/validate_v36_prop_sample.py` — размеры, PNG/SHA, цвета общей палитры, бинарная альфа, опоры и стык двух деталей, размеры в метрах, отдельные столкновения, область стекла и нормализованные векторы рельефа.

Отдельная сцена Godot 4.4.1 Compatibility: дневной вид рядом с текущим Рико высотой 1.75 м, нормаль вкл/выкл, вечерняя эмиссия вкл/выкл и настоящий свет. При включении только эмиссии изменились 2746 пикселей, **за областью стекла — 0**. Нормаль изменила 11064 пикселя изображения. Итог — `V36_PROP_RENDER_OK`; ошибок движка нет, только системное предупреждение V-Sync. Эти числа относятся к контрольной камере, не к устройству игрока.

Обзор: `astra/previews/v36/modular_48_review.png`. Контрольные дневной/вечерний кадры помечены `modular_48_qa_*`; это отдельная проверочная сцена, **не основной прототип и не готовая игра**. Новый арт ещё нужно поставить в настоящий прототип, сравнить с концептом при штатной камере и получить художественную оценку владельца. Остальную партию по этому образцу пока не начинать.

Воспроизведение (Blender 4.3, Python с Pillow/NumPy; к запуску игры эти инструменты не относятся):

```bash
export TRASHSQUAD_V36_RENDER_DIR=/tmp/trashsquad-v36-native
blender -b -t 4 --python tools/art_v36/model_props.py -- lamp
blender -b -t 4 --python tools/art_v36/model_props.py -- pedestal
blender -b -t 4 --python tools/art_v36/model_props.py -- planter
python tools/art_v36/bake_pixels.py
python tools/art_v36/deliver_sample.py
python tools/validate_v36_prop_sample.py
```

Первые два отвергнутых набора и их генераторы не используются. Web/APK не выпускаются этим пакетом.
