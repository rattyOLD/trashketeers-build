# v36 — контрольный комплект 96 px/м

Три новых игровых спрайта: фронтальный стройный фонарь, массивная резная тумба и пышная кадка. Это следующий образец после Рико96, **комплект принят владельцем 17.10 как уровень концепта**. Материалы192, остальные предметы, фасады и анимации не начинались.

Сборка занимает192×332, видимая высота330px=3.4375м. Силуэты фонаря86×182 и тумбы142×174: отношение высот1.046. Ширина тумбы включает свисающий плющ. Сокет тумбы **[96,26]**, подъём фонаря **148/96м**. Столкновение сборки принадлежит только тумбе; фонарь на ней без собственного столкновения. Смещение к камере0.005м в общей плоскости защищает от z-fighting.

## Подключение

Плотность **96 px/м**, размеры и опоры из manifest.json. pixel_size=1/96; для центрированного Sprite3D offset=Vector2(width/2-anchor_x,anchor_y-height/2). Масштаб не подбирать по прозрачному холсту. Альфа0/255, альфа-срез0.5, nearest с допустимыми mipmaps, непрерывная тёмная обводка1px. Общая палитра этих трёх предметов — **../palettes/bank96.png,128цветов**; старый bank.png сохранён для прежних материалов48px/м. Общая палитра главы ещё не сведена.

Нормали камня: OpenGL+Y, linear data, invert_y=false, начать с0.45. Это вручную заданные плоскости/фаски и профиль резной панели, **не нормаль по яркости и не скан поверхности**. Геометрия приблизительная; фактура цвета сама по себе не превращается в рельеф.

Свечение — **EMISSION_OP_MULTIPLY**. Маска:0 у корпуса/крыши/переплётов/блика,48 у приглушённого стекла,255 у нити. Маску не бинаризовать. Днём эмиссия0; вечером начать с0.45, цвет#ffc574, OmniLight0.4, радиус5м. Положение лампочки относительно опоры — в manifest. Два внутренних переплёта сохраняют нулевую маску.

## Подготовка и проверка

Владелец разрешил подготовку от концепта. Крупный исходник astra/previews/v36/props96_source.png — **не игровой спрайт**. Материалы с него выбраны медианными пробами на конечной сетке, сведены в общую палитру, очищены локальные одиночные близкие оттенки, добавлен полный тёмный контур. Это концептная основа с пиксельной очисткой, не нативный3D-рендер и не растяжение прежних48px PNG. Падающей тени на землю в albedo нет.

Воспроизведение:

```bash
node tools/art_v36/prepare_props96.mjs astra/previews/v36/props96_source.png /tmp/props96
python tools/art_v36/deliver_props96.py /tmp/props96
python tools/validate_v36_prop_sample.py
python tools/art_v36/qa_plaza.py /tmp/props96-plaza --rico-dir astra/inbox/hd2d_test/chars
python tools/art_v36/qa_props96.py /tmp/props96-plaza
```

Последняя команда добавляет props_review.tscn. В отдельном проекте сначала выполнить импорт Godot4.4.1, затем запустить review.tscn и props_review.tscn с графическим драйвером Compatibility; dummy/headless не подтверждает отрисовку. Проверки пар кадров: check_plaza_review.py и check_props96_render.py. Старые model_props/bake_pixels/deliver_sample — история48px/м, не генераторы текущего комплекта.

Проверены пять PNG: CRC/SHA, физический масштаб, палитра128, жёсткая альфа, полный контур, одна связная фигура каждого предмета, крепление, нормали, три секции маски. Повторный экспорт побайтно идентичен. Отрицательный контроль со сплошным стеклом и правильными SHA/размерами отклонён по переплётам.

**Godot4.4.1 Compatibility:** только включение эмиссии изменяет800px, за проекцией стекла0; нормаль камня изменяет16183px. День/вечер сняты в отдельной копии настоящей площади рядом с новым Рико96. Ошибок сцены/скриптов нет, только системное предупреждение V-Sync. RENDER_VALIDATION.json фиксирует условия. Превью: props96_plaza_day/evening.png и props96_material_review.png.

Площадь сохраняет временные фасады и прежние материалы48px/м: это контроль масштаба и предметов, **не завершённая сцена уровня концепта**. Мобы скрыты, персонаж заморожен; боя/анимаций/телефонов здесь не проверяли. Размытие/свечение Compatibility — экранный mip-проход прототипа, не физическая DOF камеры. Рабочий source/, main, Web/APK не изменены.
