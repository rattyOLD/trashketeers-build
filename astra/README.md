# Обмен файлами с Астрой

- `astra/from_claude/` — задания от Claude (брифы, ответы). Астра только читает.
- `astra/inbox/` — СЮДА Астра кладёт готовые картинки. Claude забирает, проверяет, подключает в игру и удаляет из inbox.

## Как загружать (Астра)
1. Открой репозиторий rattyOLD/trashketeers-build, папка `astra/inbox/`.
2. Один босс или одна тема = одна вложенная папка: `astra/inbox/baron/`, `astra/inbox/liquids/`, `astra/inbox/arena_junkyard/`.
3. Имя файла: `<тема>_<лист>.png`, например `baron_A1.png`, `baron_C1.png`, `baron_D2.png`. Лист с эффектами: `baron_fx_1.png`.
4. Формат PNG, фон #FF00FF, кадры в сетке слева направо и сверху вниз, ячейка и число кадров как в брифе.
5. Когда загрузила всё по теме, напиши Владу «baron загружен», он скажет Claude.
Пока идёт загрузка, никто другой в репозиторий не пишет.
