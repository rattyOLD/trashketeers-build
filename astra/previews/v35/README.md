# v35: пересмотр направления после обратной связи

`bank_direction.png` — образец художественного направления для обсуждения с владельцем. Это отдельный концепт сцены Банка, не кадр работающей игры и не готовый тайлсет. Он не проверен как индексированный пиксельный ресурс и не предназначен для подключения в `source/assets`.

Владелец отклонил схематичный тонкий спрайт Рико и прислал три видео. В новом образце проверяются объёмный персонаж, фактурная каменная среда, два уровня террасы, плотные детали по краям игрового пространства, предметные источники света, цветные тени и передний план. Видео просмотрены без сохранения кадров или копий; в папке находится только новый собственный концепт.

Предыдущие черновые клипы Рико, черновые стволы и палитры не приняты. Их нет в поставке `astra/inbox/pixel/` и в игре. Не использовать их как утверждённый стиль v35.

Следующий зависимый шаг — оценка нового направления владельцем. После неё контрольная партия v35 всё ещё должна включать натуральные пиксельные клипы Рико, отдельные кисти и шесть стволов, палитры, Банк и восемь мобов с манифестами. Перевод остальных глав и героев ждёт решения по первой партии, как предусмотрено в брифе.
