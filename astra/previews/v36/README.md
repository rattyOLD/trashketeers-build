## Новый образец

`prop_direction.png`: крупный рисунок фонаря на каменной тумбе с цветочной кадкой. Цель — убедительная толщина металлических деталей, материал стекла, резной камень, объёмная керамика, сложные органические формы растений; по качеству он должен соответствовать выбранному концепту площади.

**Это образец направления, не готовый игровой спрайт.** В частности: 1145×1374, свободная палитра, есть промежуточная альфа; сетка натурального пикселя и плотность 32 px/м не подтверждены. Нельзя уменьшить его, положить в inbox и объявить v36 выполненным.

Следующая проверка — отдельный предмет в натуральном игровом размере, рядом с Рико в 3D-площади при нейтральном и вечернем освещении. Сравнивать нужно при обычной камере, а не только на крупном рисунке. Только после этого переносить подход на остальной набор. Качество требует проверки силуэта, материала и объёма; свечение и размытие не должны скрывать плоский исходный рисунок.

Ролики просмотрены в памяти; кадров и копий в репозитории/файлах нет. Для нового рисунка использован только собственный концепт Банка из предыдущего прохода. Видео владельца генератору не передавались.
