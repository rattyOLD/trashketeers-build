# Астра — бриф v12b: бестиарий (отдельно от блока M) — 02.10

Выделил из v12 (M6), чтобы было проще. Решение Влада: бестиарий показывает ВСЕХ врагов и боссов: сейчас 27 врагов и 7 боссов, позже ещё 3 агента Бюро из K1. У каждого есть запись «слабость / подсказка» одной строкой (текст пишу я). Запись открывается, когда игрок впервые встретил врага, до этого карточка закрыта. Готовые спрайты врагов в игре есть, портреты рисовать не нужно. От тебя только оформление, всё без текста. Правила прежние: фон #FF00FF, толстый тёмный контур #1A0033, не пиксель-арт, свет сверху-слева. Загрузка папкой `astra/inbox/story/bestiary/`, по готовности: «бестиарий загружен».

- Карточка врага 384×512, фиксированная, центр пустой под спрайт. Три вида рамки: обычный враг (ржавая), элита (неон), босс (золотая с шипами). Под спрайтом место под название и строку «слабость» (текст ставит код).
- Закрытая карточка 384×512: тёмный силуэт-заглушка «?» из неоновой трубки, одна на все виды.
- Значки 96×96: «слабость» (трещина в щите), «подсказка» (лампочка из крышки), «новый» (звезда-пробка), «закрыто» (замок), «побеждён» (череп с галочкой), «убито N» (мишень).
- Значки типа врага 64×64 для фильтров, 9 штук: бегун, стрелок, рывок, бомбист, молот, ловушка, обманщик, убийца, босс.
- Баннер экрана 1024×256: свалка, крысы за решёткой с лупой.
- Иконка бестиария для меню 512×512 в стиле L4: раскрытая книга с когтистым отпечатком.

Объём: 3 рамки + 1 заглушка + 6 значков + 9 значков типа + баннер + иконка меню = 21 файл. Порядок: рамки и заглушка, потом значки, потом баннер и иконка.
