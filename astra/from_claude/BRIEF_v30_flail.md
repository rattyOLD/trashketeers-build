# Астра: бриф v30 — Моргенштерн «Цепной пёс» (09.10)

Новое оружие по идее тестеров: шар с шипами на цепи, крутится вокруг героя по инерции. Код уже работает на временной графике (рисуется кодом). Стиль v21, PNG прозрачный.

Папка `astra/inbox/weapons/flail/`:
- `flail_handle.png` — рукоять в руке героя (как другие стволы в руке: ~150×60, хват слева, конец цепи справа), из хлама: кусок трубы, обмотка изолентой;
- `flail_ball.png` — шар 64×64: ржавая гиря/шестерня с шипами из болтов, вид сверху-сбоку; `flail_ball_fast.png` — тот же с размытием движения (4 кадра в ряд 96×64);
- `flail_link.png` — одно звено цепи 16×16 (игра выкладывает их по цепи);
- `flail_icon.png` — иконка для меню 256×128 (как у других стволов);
- `flail_hit.png` — вспышка удара шаром, 4 кадра 128×128 (оранжевые искры, кусочки хлама).
