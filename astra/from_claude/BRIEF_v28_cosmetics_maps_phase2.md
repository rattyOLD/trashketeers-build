# Астра: бриф v28 — косметика, карты с редкостью, вторая фаза оружия (09.10)

Влад одобрил идеи тестеров: косметика из сундуков и за рекламу, карты Выживания с редкостью (своя рисовка и фишки), «вторая фаза» оружия после босса. Код я делаю сейчас на временной графике (цвета и формы), твои рисунки заменят её по мере загрузки — игра подхватит файлы по именам ниже без переделки.
Стиль прежний (v21: толстый тёмный контур, cel-shading, без крови, без букв). PNG с прозрачным фоном, ≥24 px между ячейками, всё «лицом вправо». Пиши Владу «<пачка> загружена» после каждой.

Порядок важности: **1 → 3 → 2 → 4**. Бриф v27 (герои, враги) не отменяется — Шэдоу уже в игре, спасибо! Дальше по v27 идут Турбо, Фаззи, Дон.

## 1. Косметика рывка и выстрела — `astra/inbox/cosmetics/`
### 1а. Скины рывка `dash/<id>/`
Каждый: `trail.png` — полоса шлейфа 256×64 (горизонтально, яркий «хвост» справа, тает влево); `burst.png` — вспышка старта/финиша рывка, 6 кадров 128×128 в ряд; `bit.png` — частица-примета 32×32 (1–3 варианта в ряд).
| id | Название | Редкость | Идея |
|---|---|---|---|
| `ember` | Угли | обычный | оранжевые искры и дым |
| `toxic` | Кислота | обычный | зелёные капли и пузыри |
| `neon` | Неон | редкий | розово-голубые неоновые полосы |
| `void` | Пустота | эпический | фиолетово-чёрный разрыв, звёздочки |
| `gold` | Золотой рывок | легендарный | золотые монеты-крышки и блеск |
| `cat` | Кошачий след | легендарный | розовые лапки-следы и сердечки |

### 1б. Трассеры и свечение пуль `shot/<id>/`

### 1в. Иконки для витрины сундука и меню — `icons/` 256×256
По одной на каждый id из 1а и 1б: `dash_<id>.png`, `shot_<id>.png` (герой не нужен — эффект крупно, читается в маленьком размере).

## 2. Карты Выживания с редкостью — `astra/inbox/maps/<id>/`
Игрок выбивает «карту» из сундука и выбирает её перед Выживанием: своё настроение, свои враги и правила, больше награды. Для каждой: `card.png` — карточка-обложка 512×720 (вид на карту сверху, рамка цвета редкости рисуется кодом), `floor.png` — бесшовная плитка пола 512×512, `props/` — 4–6 своих пропов-укрытий (по одному PNG, ноги на нижней линии, 160–320 px), `decals/` — 3–4 декали пола 128–256.
| id | Название | Редкость | Фишка (код уже делаю) |
|---|---|---|---|
| `night_dump` | Ночная Свалка | редкая | вечная ночь, костры, фонари гаснут; крысы шустрее |
| `acid_rain` | Кислотный ливень | эпическая | ливень, лужи кислоты растут; больше токсичных крыс |
| `neon_market` | Неоновый рынок | эпическая | розовая дымка, ларьки и гирлянды; курьеры с лутом |
| `gold_vault` | Золотое хранилище | легендарная | золото на полу, инкассаторы; монеты ×1.5 |
| `pigeon_roofs` | Голубиные крыши | легендарная | крыши, трубы, антенны; голуби-бомбардиры роями |
Для каждой ещё по одному **уникальному врагу** (`enemy_<id>`: idle 4, run 6, strike 4, death 6, ячейка 256×256): ночной — крыса-фонарщик, ливень — кислотный слизень, рынок — крыса-лоточник с тележкой, хранилище — свин-сейф на ножках, крыши — голубь-кровельщик.

## 3. Вторая фаза оружия — `astra/inbox/vfx_v2/phase2/`
После первого босса оружие «раскрывается» (карточки второй фазы). Нужны эффекты, 6 кадров в ряд:
- `flying_slash` — летящий серп-слайс (топор/меч/катана) 192×96, вправо;
- `blink_cut` — разрез по линии рывка катаны: длинная световая черта 512×64;
- `echo_ring` — ударная волна молота 256×256;
- `split_shot` — пуля, распадающаяся на три 128×64;
- `overheat` — пар и раскалённый ствол для пулемёта 128×128;
- `phase2_badge` — значок «ФАЗА 2» без букв: скрещённые клинок и ствол в огне, 256×256 (для карточек и HUD).

## 4. Сундук и реклама
- `chest_cosmetic.png` — «стильный» сундук косметики (неоновая коробка с парашютом), закрытый/открытый 2 кадра 384×384;
- `ad_gift.png` — иконка «подарок за рекламу» 128×128 (телевизор с бантом).
