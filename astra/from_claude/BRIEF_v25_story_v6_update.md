# BRIEF v25: обновление под сюжет v6 «72 часа» (дополняет v22, v23, v24)
Стиль общий: наш тактический, top-down, магента-фон, без крови, для всех возрастов. Где v22-v24 противоречат этому брифу, действует v25.

## Новые названия и эмблемы
- АКВИЛОН ГРУПП (ЧВК): эмблема «северный ветер» (компас-спираль), графит+белый+красный акцент. Нужны: логотип 512, нашивка 128, табличка на КПП/воротах/стенах 256×128, стикер на технику, штамп на документах.
- БЮРО ЛИКВИДАЦИИ (секретный отдел): эмблема чёрная лента + чёрная птица (стрела), штамп «ЛИКВИДИРОВАТЬ» красный, штамп «УТИЛИЗИРОВАН».
Заменяем везде, где был «Бюро расчистки».

## Боссы Бюро (ровно две «шишки»)
1. ВДОВА (босс конца М5): элегантная кошка в чёрном, два клинка/пистолета, длинное пальто, вуаль. Сетка 4×2 384×512 + портрет 512 (normal/alt) + иконка. Атаки: рывок-невидимость, веер клинков, серия выстрелов, фаза 2 (сброс вуали). Смерть без крови (рассыпается в чёрные перья/лепестки).
2. ДИРЕКТОР (финал М6): старый, спокойный, административный экзоскелет (костюм+стальной каркас), зонт-трость как оружие, очки. Сетка 4×2 + портрет + иконка. Фазы: стол/приказы, экзоскелет, режим «последний сотрудник».
Мини-боссы («руки Бюро», не шишки): АГЕНТ 007-ШТ (М3, смокинг, часы-гаджет, дымовые шашки), ХИТМАН-47 (М4, лысый бульдог, чемоданчик, штрих-код на затылке). Меньшая детализация: ходьба, 3 атаки, смерть, портрет, иконка.
Обычные: Тихий агент и Агент-снайпер (v23, без изменений).

## Карточки глав (в стиле кино, UI)
6 карточек 720×300: «Глава 1: ЧЕЛОВЕК В СПИСКЕ», «Глава 2: БАНК, НЕ ДЛЯ КЛИЕНТОВ», «Глава 3: СВЯЗЬ ПРОПАЛА», «Глава 4: ТИХИЙ ЧАС», «Глава 5: ПОРТ», «Глава 6: ПОЛЮС». Чёрный фон, тонкая красная линия, шрифт заголовка в духе старых титров. Плюс «Глава 0: Три года назад» (для флэшбека).

## Сюжетные предметы и UI
- Рубильник Нэлл: круглый таймер 72 часа (кольцо, центр чашка чая), 3 состояния: спокойно, «чай стынет», «чай остыл». Иконка 128 + виджет 256.
- Список имён на табло: плашка с 6 именами героев + красная зачёркивающая линия (штамп), как на доске в офисе Бюро. Размер 640×400.
- Бухгалтерия «управляемых конфликтов»: страница документа 600×800 (города, суммы, подписи, штамп «АКВИЛОН ГРУПП»).
- Страховой полис Дона: документ 600×800 (выгодополучатель Бюро).
- Подделка голоса Кейт: иконка «волна с трещиной» 128 для реплик.
- Пакет флэшбека, выбор, полка памяти, эмоции Рико/Нэлл, концовки: без изменений из v24.

## Локации (Бюро присутствует в каждой главе)
- М1: КПП «Пост 7» (шлагбаум, будка, прожекторы, знаки Аквилона).
- М2: офис «Взыскание» на этаже банка (кубикли, шредеры, табло KPI, переговорные).
- М3: узел связи на вышке (антенны, серверная кабина, кабели).
- М4: Холодный склад + заброшенный объект-бункер (бетон, камеры хранения, стеклянные стены; допрос показываем намёком: стул, лампа, разбитые очки, без жести).
- М5: портовый терминал Бюро (контейнеры с маркировкой, радарная рубка).
- М6: база «ПОЛЮС» в Антарктиде (лёд, ангар, станция, серверный зал с шестью замками).
